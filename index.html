Security — Known & Unknown Attacks (College Project)

Example model for college project. See SECURITY.md for full docs.

SQL Injection — blocked

SQL injection happens when an app builds SQL queries by concatenating user input into the query string. An attacker can then craft input that changes the meaning of the SQL (for example, turning a login check into “always true”).

XSS — blocked

Injecting scripts via user input can steal data. We use textContent and escapeHtml() so output is safe.

CSRF — mitigated

Bearer tokens in headers (not cookies) prevent cross-site request forgery.

Unknown attacks — defense in depth

Multiple layers (validation, encoding, secure auth) make new attack vectors harder to exploit.

Passwords: secure hash (Werkzeug), not plain text.
